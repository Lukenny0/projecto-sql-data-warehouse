# Construção do Data Warehouse (Engenharia de Dados)

## Objectivo

Desenvolver um Data Warehouse moderno, utilizando o SQL Server, para
consolidar os dados de vendas, permitindo a elaboração de relatórios
analíticos e a tomada de decisões fundamentadas.

## Especificações

-   **Fontes de dados:** Importar dados de dois sistemas de origem (ERP
    e CRM), disponibilizados em ficheiros CSV.
-   **Qualidade dos dados:** Limpar os dados e corrigir os problemas de
    qualidade identificados antes da sua análise.
-   **Integração:** Combinar os dados das duas fontes num único modelo
    de dados, intuitivo e adequado à realização de consultas analíticas.
-   **Âmbito:** Trabalhar apenas com o conjunto de dados mais recente.
    Não é necessária a manutenção de histórico dos dados.
-   **Documentação:** Disponibilizar documentação clara do modelo de
    dados, de modo a apoiar tanto as áreas de negócio como as equipas de
    análise de dados.

# BI: Análise e Relatórios (Análise de Dados)

## Objectivo

Desenvolver análises baseadas em SQL para fornecer informações
detalhadas sobre:

-   **Comportamento dos clientes**
-   **Desempenho dos produtos**
-   **Tendências de vendas**

Estas análises permitirão disponibilizar aos responsáveis pelas áreas de
negócio indicadores-chave de desempenho, apoiando a tomada de decisões
estratégicas.
